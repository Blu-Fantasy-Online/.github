### Hytale/Minecraft Plugins
- **BFO | MysticRealms**: By **MysticMight** TBA
- **BFO | MysticChat**: By **Kerzinator_24** TBA
- **BFO | BluRPG Engine**: An RPG framework for Hytale servers, bringing together configurable archetypes, progression, skills, combat, parties, and alliances.
- **BFO | BluRPG Editor**: An Custom class and skill designer for BluRPG.
- **BFO | BluRPG Items**: An RPG item generator project for BluRPG and Hytale servers.
- **BFO | BluMMO Engine**: An activity and content engine for Hytale servers, covering dungeons, raids, mazes, quests, and PvP. BluRPG handles progression and parties; BluEconomy handles currency.
- **BFO | BluServer Router API**: The BFO server router provider connects participating Hytale nodes and coordinates validated player transfers for BluMMO Engine.
- **BFO | Dreamscape**: World tools for Hytale servers: protected regions, seasons, ambience, managed world generation, music, and rollback-aware administration.
- **BFO | BluEssentials**: Everyday Hytale server utilities for travel, homes, social features, chat, kits, moderation, announcements, and player support.
- **BFO | BluEconomy**: A Hytale economy plugin for persistent balances, player payments, currency trading, shop browsing, lottery, daily rewards, battle pass systems and configurable rewards.
- **BFO | BluSchemConverter**: Convert Minecraft .schem and legacy .schematic builds into Hytale prefab JSON, then paste them in-game with progress, cancellation, and undo controls.
